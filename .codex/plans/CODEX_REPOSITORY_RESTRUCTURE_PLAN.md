# Codex 仓库重构历史计划

> 历史材料，以当前代码、测试和最新报告为准。

本文归档 2026 年 7 月仓库重构的原始方向，不再作为待执行清单。

## 当时识别的问题

- 项目价值、业务闭环和个人贡献入口不够集中。
- 工程规则、模块说明、模拟证据与安全边界分散。
- 历史计划与当前实现容易混淆。
- 远端 About、Topics、预览图和展示入口需要单独治理。

## 当时采用的阶段

1. 建立 `.codex/` 执行规则与文档索引。
2. 重组 `docs/` 信息架构并保留历史材料。
3. 为 Web、Admin 和共享包补充模块说明。
4. 建立模拟方法、指标字典、复现命令与结论报告。
5. 增加贡献、安全、Issue/PR 模板和质量门。
6. 在验证后处理 GitHub 远端设置。
