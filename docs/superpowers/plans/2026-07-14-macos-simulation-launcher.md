# macOS 模拟工作台启动器历史实施计划

> 历史材料，以当前代码、测试和最新报告为准。

## 当时目标

为 macOS 提供可重复的模拟工作台启动入口，负责环境检查、依赖准备、固定命令启动和可理解的失败提示。

## 当时范围

- 检查 Node.js、pnpm、仓库路径和必要环境变量。
- 启动模拟相关应用并保留可诊断日志。
- 避免写入凭证、生产数据或被跟踪的模拟原始产物。
- 为启动脚本和关键路径补充静态检查。

## 当前使用边界

启动方式、端口和脚本位置可能已经变化。使用前应先查看当前 `package.json` 与 [`docs/simulation/delivery-guide.md`](../../simulation/delivery-guide.md)，不能把本历史计划当作现行命令说明。
