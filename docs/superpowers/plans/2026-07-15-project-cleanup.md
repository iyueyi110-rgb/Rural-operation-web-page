# 项目清理历史实施计划

> 历史材料，以当前代码、测试和最新报告为准。

## 当时目标

在不删除用户状态、不改写共享历史的前提下，清理可确认的构建缓存、运行日志与忽略产物，并形成可复核的操作记录。

## 当时任务

1. 加固清理说明和目标路径校验。
2. 保留并修订尚未发布的清理提交。
3. 提交经审查的操作手册。
4. 同步分支并运行验证。
5. 只发布一次并记录结果。

## 安全边界

- 删除前必须解析并核对绝对目标路径。
- 不删除工作区根、用户目录、凭证、数据库或用户未跟踪资料。
- 当前清理规则以 [`.codex/cleanup-workflow.md`](../../../.codex/cleanup-workflow.md) 为准。
