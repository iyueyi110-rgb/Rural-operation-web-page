# Admin BFF 与模拟运行分页历史实施计划

> 历史材料，以当前代码、测试和最新报告为准。

## 当时目标

让浏览器通过可信的同源 Admin BFF 获取模拟运行列表，并通过摘要投影与有界稳定分页避免泄露服务端 token 或返回过大的运行载荷。

## 当时任务

1. 建立管理员会话与同源 BFF 访问边界。
2. 增加模拟运行摘要投影和稳定分页。
3. 适配 Admin 响应封装并补充测试。

## 约束

- `ADMIN_API_TOKEN` 只存在于服务端。
- 分页顺序和边界必须可测试，失败不得伪装成空成功。
- 本文不作为当前 HTTP 合约，当前实现以代码和测试为准。
