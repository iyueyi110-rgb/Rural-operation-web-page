# 调研证据与产品决策

## 文档用途

本页只公开可复核的方法、结论和决策边界，不替代未公开的访谈原始记录。涉及村书记、村民和个人信息的材料不进入公开仓库；公开内容不编造用户原话，也不把沟通人次写成去重用户数。

## 调研范围

| 项目 | 公开结论 |
| --- | --- |
| 沟通对象 | 村书记、村民和乡村文旅协作相关人员 |
| 沟通规模 | 12 人次；不等于 12 位去重用户 |
| 调研目的 | 在多个乡村文旅候选方向中选择一条优先验证链路 |
| 当前结论 | 优先验证荔枝树认养，因为它同时连接长期用户关系、村民养护任务和运营审核 |
| 证据等级 | C：私有材料；原始记录未公开 |

| 假设 | 当前依据 | 当前状态 | 下一步验证 |
| --- | --- | --- | --- |

## 产品决策记录

### 决策 1：优先做认养履约，而不是先做门票或住宿

- **背景问题**：门票和住宿可以形成一次性交易，但不能直接验证用户关系、村民任务和长期权益是否能持续运转。
- **候选方案**：门票预购、院落预约、研学活动、荔枝树认养。
- **选择结果**：以 `LZ-018` 认养履约作为第一条垂直链路。
- **选择依据**：一棵树可以同时关联树档案、养护任务、凭证、成长记录、权益、结算和续养。
- **放弃方案**：门票、住宿和研学保留为后续扩展，不作为当前 MVP 主叙事。
- **后续验证**：用小规模试点验证用户是否愿意持续查看、村民是否能按时履约、运营是否能控制审核成本。

### 决策 2：高风险状态必须人工确认

- **背景问题**：退款、判责、结算和履约状态变更会直接影响用户权益和村民收益。
- **选择结果**：Agent 只读取必要信息并生成建议，运营人员确认后才能推进高风险动作。
- **选择依据**：当前 Agent 未产生足够真实模型建议，不能计算采纳率、漏检率或错误重派率。
- **后续验证**：模型可用后先运行影子模式，再单独评估建议质量，不改变人工门禁。

### 决策 3：暂不接入真实支付

- **背景问题**：当前项目用于产品验证和公开演示，尚未完成支付资质、回调、对账和退款责任链路。
- **选择结果**：保留待支付演示状态；退款只创建人工审核工单，不发生真实扣款或真实退款。
- **选择依据**：避免把演示状态伪装成真实交易结果，也避免在未完成财务边界前扩大风险。
- **后续验证**：真实试点前补充支付服务、幂等、对账、退款和审计方案。

### 决策 4：模拟结果不能直接宣布规则升级

- **背景问题**：固定种子和场景模拟可以比较规则，但不能代表真实用户、村民或收益结果。
- **选择结果**：40 组 V0/V1 结果只用于发现 Bad Case、校准口径和决定下一轮实验。
- **选择依据**：升级门槛同时检查履约时效、审核、异常、人工介入和公平性，不能因单个指标改善就升级。
- **后续验证**：先完成脱敏试点和人工复核，再判断模拟规则是否与真实分布接近。

## 未公开材料边界

- 访谈名单、联系方式和原始逐字记录不公开。
- 当前公开仓库没有足够材料支持新增真实用户原话，因此本页不虚构引语。
- 调研结论属于 C 级证据；真实用户行为、村民效率和运营收益仍属于待验证结果。
