# 功能状态与实现边界

本页统一产品文档、作品集和当前代码的功能状态。代码、测试和最新实施报告是实现事实的最终依据；“不属于当前 MVP”表示不进入认养履约主叙事，不代表仓库中一定没有对应演示页面。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已实现并可演示 | 当前仓库存在页面或接口，并有对应测试或实施证据 |
| 已实现但仅为模拟 | 存在可重复实现，但数据和结果不能代表真实业务 |
| 设计完成但未接入 | 已定义流程或接口边界，但缺少真实外部服务或生产条件 |
| 后续规划 | 当前没有可作为完成证据的实现 |
| 不属于当前 MVP | 可能已有演示能力，但不用于证明认养履约核心价值 |

## 演示降级边界

- PostgreSQL 不可用时，公开页面可以使用明确标识的降级数据完成浏览和构建。
- 鉴权写操作、审核和结算不能因为进入演示模式而伪造成功。
- Admin 后端不可用时必须显示可识别的错误或降级状态。
- 模型密钥不可用时使用受控降级；履约 Agent 不生成虚构建议。
